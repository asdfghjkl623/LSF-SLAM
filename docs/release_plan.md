# Release Plan

This repository currently provides a preliminary project and dataset description based on the LSF-SLAM paper draft. The release will be expanded in stages.

## Stage 1: Preliminary Repository Page

Status: in progress.

Planned contents:

- project overview;
- dataset motivation;
- six-sequence summary table;
- sensor and platform description;
- placeholder for Google Drive download links;
- citation placeholder.

## Stage 2: Initial Dataset Package

Planned contents:

- short-focal and long-focal synchronized image streams;
- timestamps;
- sequence metadata;
- Google Drive download link;
- archive size and checksum information.

## Stage 3: Calibration and Reference Files

Planned contents:

- camera intrinsic parameters;
- camera extrinsic parameters;
- sensor-frame definitions;
- RTK/GNSS reference trajectory files;
- coordinate-system notes.

## Stage 4: Evaluation Tools

Planned contents:

- ATE evaluation script;
- RPE evaluation script;
- example command lines;
- expected output format;
- baseline configuration notes where release is permitted.

## Stage 5: Final Paper Metadata

Planned contents:

- final BibTeX entry;
- DOI or publication URL if available;
- license information for code and dataset;
- known issues and FAQ.
